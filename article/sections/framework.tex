The comparisons of Section~\ref{sec:results} combine into one configuration for grading with an LLM
(Table~\ref{tab:framework}, Fig.~\ref{fig:frameworkdiagram}). Give the model the rubric or the reference
answer and ask it to award partial credit. Grade one question per call, with reasoning off and a single
holistic score, in a clean conversation for each answer. The guide sets how the grader is configured and
leaves the choice of model open, so we validated it on all five models of the study.

Two settings carry the gain. The rubric or the reference answer raised agreement significantly in 13 of 15
model-dataset combinations, by 0.10 to 0.34 QWK (Section~\ref{sec:rq2}), and the request for partial credit raised code
agreement by up to 0.11 for a few extra input tokens (Section~\ref{sec:rq6}). The other four settings keep
grading cheap, consistent, and fair. Reasoning raised agreement significantly in only six of twenty
combinations, at 9 to 925 times the output tokens (Section~\ref{sec:rq1}); grading the whole exam in one call never improved
agreement, and scoring criterion by criterion did so once (Section~\ref{sec:rq3}); and a clean conversation
keeps each grade independent of the answers graded before it (Section~\ref{sec:rq5}).

We validated the guide with two tests that use every configuration graded in the study. The first asks
whether another configuration of the same model agrees better with the teachers. The second asks how the
guide, with each model, compares with the best configuration of any model, and at what cost.

\emph{Test 1: the same model, configured otherwise.} Without reasoning, no other configuration of the same
model agreed significantly better with the teachers than the guide's, with one exception in 56 comparisons
(Table~\ref{tab:framework}). Each comparison pairs the guide's configuration with another configuration of
the same model on the answers both graded, using the bootstrap of Section~\ref{sec:metrics} without
correction for multiple comparisons, which makes an advantage of the alternative easier to detect. The
exception is the strict instruction for Claude Sonnet 4.6 on the 84 PT-CS short answers, by 0.043 QWK.
Thirty-three alternatives agreed significantly worse, by up to 0.34, and no alternative to the guidance,
the scope, the decomposition, or the clean conversation agreed better for any model. Turning reasoning on
was the only change that raised agreement more than once: it did so significantly in 7 of 17 comparisons,
five of them for Qwen3.5, the model with the strongest zero-collapse, and never lowered it, but it made
grades less consistent across repetitions in 14 of the 17 and cost 2.6 to 179 times as much per grade.
The other alternatives also made grades less consistent in most comparisons (34 of 56).

\emph{Test 2: every configuration in the study.} With the model best suited to each dataset, the guide's
configuration reached or approached the best agreement in the study (Fig.~\ref{fig:guidevalidation}): it
was the best configuration on Mohler (GPT-5.1, 0.653 QWK) and on PT-CS code (DeepSeek-V4-Flash, 0.674), and
came within 0.002 of the best on SemEval, 0.014 on RIAYN, and 0.043 on the PT-CS short answers. On the
sampled answers, which also include the configurations with reasoning, the best configuration led it by at
most 0.053. With four of the five models it graded code at 0.65 to 0.76 QWK, and with Qwen3.5 at 0.50 and
0.55, as that model's zero-collapse persisted under partial credit (Section~\ref{sec:rq6}). With the
cheapest model, DeepSeek-V4-Flash, the guide cost 0.02 to 0.09 euros per thousand grades, and no cheaper
configuration agreed better, apart from a difference of 0.001 QWK on SemEval.
