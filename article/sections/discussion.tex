\section{Discussion}
\label{sec:discussion}

Read together, the results point to one practical message: what the grader is given, and how the prompt tells it
to use it, mattered more than how long it thinks or how much it costs. The cheap changes gave the clearest gains:
a rubric or reference answer raised agreement almost everywhere, partial credit helped on code for a few extra
tokens, and the code prompt removed most of the zero-collapse for a short statement before the score. Reasoning,
a closed model, a whole exam in one call, and criterion scoring cost more or saved little; only reasoning brought
the grades closer to the human graders' with any regularity, and mostly on code.

Reasoning is the expensive setting with the most uneven return: significant gains in five of twenty
combinations, at up to 925 times the output tokens, and less consistent grades in most. Longer outputs give a
non-deterministic backend more room to diverge, but length explained the extra variability only moderately, so
part of it behaves like a property of reasoning itself. Nor is consistency the same as quality: the most
reproducible grader, Qwen3.5, had the strongest zero-collapse.

The zero-collapse explains where reasoning paid, and the follow-up showed that the prompt can remove most of it.
Graders that are too severe have been described
before~\cite{pathak_rubric_2025,venkatraman_llmbased_2026,sapkota_math_2026}, and the zero-collapse is a specific,
measurable form of that severity. The models' own justifications show its cause: they often named what the student had done right,
then withheld every mark because the answer departed from the letter of a rubric item, as if each item were a
pass-or-fail test. A prompt that tells the grader to credit each item on its own, as a teacher grades a written
exam, and to state what earns marks before the score removed most of these zeros without reasoning. Much of what
reasoning bought on code was therefore a repair that the prompt makes for a small fraction of the cost. The same
prompt made graders too generous on short theory answers: a remedy for one failure can create the opposite one, so its
scope matters. Model size may also play a part: four of the five significant reasoning gains belong to
Qwen3.5-35B-A3B, which activates only about 3B parameters per token and remained the weakest code grader under
the code prompt, and the gains of thinking reported for LLM judges were measured on Qwen3 models of 0.6B to 4B
parameters~\cite{jayarao_explicit_2025}. With a single small model, its size cannot be separated from its
zero-collapse.

Evaluation guidance and the prompt are the opposite case to reasoning: cheap and effective. On short answers,
guidance raised agreement by more than 0.11 QWK in eight of the nine combinations, more than the whole spread
between the eight configurations of model and reasoning. The simplest shape of the request also won: one
question per call with a single holistic score was never beaten by the whole exam, and criterion scoring beat it
only for GPT-5.1 on RIAYN, where that model gave too many zeros. A clean conversation per answer removes the
small pull of a shared history and the effect of an answer's position, so it is also the fairer choice.

Model choice mattered more on code than on short answers, largely according to whether a model showed the
zero-collapse, and the prompt changes which model is worth paying for: with partial credit, the cheapest model,
DeepSeek-V4-Flash, graded code as well as GLM-5.1, the strongest code grader without reasoning, at about a tenth
of its cost. The closed models bought little for their price. GPT-5.1 with reasoning cost 34 times as much as
GLM-5.1 without it, for 0.031 more QWK on code, and Claude Sonnet 4.6, the best configuration without reasoning on
SemEval and the PT-CS short answers, cost 43 to 53 times as much there as DeepSeek-V4-Flash with the
partial-credit prompt. Absolute levels also depend on which human grades are the reference: on Mohler, the
models' remaining error is mostly a constant offset below the teachers' grades, which a simple calibration on a
few graded answers might reduce.

The PT-CS answers, in Portuguese and graded with English prompts, reproduced the effects found on the public
datasets. Taken together, the results support one configuration built from the cheap settings, which the next
section presents, tests, and validates.
