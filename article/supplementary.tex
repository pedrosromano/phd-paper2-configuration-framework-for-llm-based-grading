This supplement gives the prompt templates, the models and their prices, the share of unparseable outputs, and tables with the values behind the figures of the paper. Every value is computed from the logged runs, with the metrics and bootstrap of the paper (QWK on six levels of the mean of the repeated grades; 10,000 resamples of the answers; 95\% intervals). The values of Fig.~1 are in Table~3 of the paper; Figs.~2 to~6, 9, and~10 have their own tables below, each naming its figure; Figs.~7 and~8 show the guide and its prompt, whose templates are given in Section~1. Section~13 gives two robustness checks: resampling whole questions instead of answers, and QWK on single runs instead of the mean of the repeated grades. A separate supplementary file holds every grade the models gave on the public and validation datasets, with a script that recomputes the reported agreement values and intervals from them.

\section{Prompt templates}
Every prompt is assembled from these blocks, in this order: the task, the guidance (omitted without guidance), the question and the student answer, and the output format. Placeholders written as \texttt{\$name} are filled for each answer. A whole-exam prompt lists every question of the exam, each with its maximum score, rubric, and student answer, after the task block. In a shared conversation the first answer is sent with the task block and every later answer as the next turn, with its question, guidance, answer, and output format. Reasoning is switched on or off through each model's settings and is never mentioned in the prompt.
\subsection*{Task, code}
\begin{Verbatim}[fontsize=\footnotesize]
You are an experienced computer-science instructor grading a student's CODE submission
for a programming exam. Assess the LOGICAL correctness of the solution against the problem
requirements. Conceptual understanding and algorithmic correctness take precedence over
minor syntax errors. Be objective and consistent.
\end{Verbatim}
\subsection*{Task, short answer}
\begin{Verbatim}[fontsize=\footnotesize]
You are an experienced instructor grading a student's SHORT ANSWER to an exam question.
Assess whether the answer is correct and complete with respect to what the question asks.
Be objective and consistent.
\end{Verbatim}
\subsection*{Guidance, rubric, strict instruction}
\begin{Verbatim}[fontsize=\footnotesize]
Grade strictly according to the following question-specific rubric. Award and deduct marks
exactly as the rubric specifies; do not invent criteria.
RUBRIC:
$grounding_body
\end{Verbatim}
\subsection*{Guidance, reference answer, strict instruction}
\begin{Verbatim}[fontsize=\footnotesize]
Use the following reference answer as the standard of a fully-correct response. The student
answer need not match it word-for-word; judge semantic equivalence.
REFERENCE ANSWER:
$grounding_body
\end{Verbatim}
\subsection*{Guidance, rubric, partial credit (the guide)}
\begin{Verbatim}[fontsize=\footnotesize]
Use the following question-specific rubric to award marks. Give the marks for every rubric item the
answer satisfies, even when the answer is incomplete or contains errors (for code, even when it would
not compile), and apply any deductions the rubric specifies; do not invent criteria. A partially
correct answer earns partial marks; give 0 only when the answer earns none of the rubric's marks.
RUBRIC:
$grounding_body
\end{Verbatim}
\subsection*{Guidance, reference answer, partial credit (the guide)}
\begin{Verbatim}[fontsize=\footnotesize]
Use the following reference answer as the standard of a fully-correct response. The student
answer need not match it word-for-word; judge semantic equivalence. A partially correct answer
earns partial marks; give 0 only when nothing in the answer is correct.
REFERENCE ANSWER:
$grounding_body
\end{Verbatim}
\subsection*{Question and answer}
\begin{Verbatim}[fontsize=\footnotesize]
QUESTION:
$question

STUDENT ANSWER:
$answer
\end{Verbatim}
\subsection*{Output, one holistic score (the guide)}
\begin{Verbatim}[fontsize=\footnotesize]
Return ONLY a single JSON object and nothing else (no markdown, no commentary):
{"score": <number between 0 and $max>}
\end{Verbatim}
\subsection*{Output, a score per criterion}
\begin{Verbatim}[fontsize=\footnotesize]
Score EACH rubric criterion, then give the total. Return ONLY a single JSON object and
nothing else (no markdown, no commentary):
{"criteria": [{"criterion": "<short label>", "score": <number>}], "total": <number between 0 and $max>}
\end{Verbatim}
\subsection*{Output, partial credit with a justification first}
\begin{Verbatim}[fontsize=\footnotesize]
First justify the score in at most two sentences, naming what the answer gets right and what it
misses; then give the score. Return ONLY a single JSON object and nothing else (no markdown, no
commentary), with the justification first:
{"justification": "<at most two sentences>", "score": <number between 0 and $max>}
\end{Verbatim}
\subsection*{Output, whole exam, one holistic score per question}
\begin{Verbatim}[fontsize=\footnotesize]
The EXAM below contains several questions, each with the student's answer. Grade EVERY
question. Return ONLY a single JSON object and nothing else, with one entry per question
(use the question_id shown for each):
{"answers": [{"question_id": "<id>", "score": <number>}]}
\end{Verbatim}
